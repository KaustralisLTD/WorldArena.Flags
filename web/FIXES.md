# 🔧 Исправления FLAGS WORLD

## Проблема 1: Статистика не сохраняется

### Описание проблемы:
- Статистика игр показывала нули на странице `/statistics/`
- Данные не сохранялись в localStorage корректно

### Исправление:
- Добавлено принудительное сохранение статистики в localStorage после каждого обновления
- Улучшена логика обновления статистики в `gameStore.ts`
- Добавлены отладочные логи для отслеживания сохранения

### Файлы изменены:
- `web/src/lib/gameStore.ts` - функция `updateStatistics`
- `web/pages/statistics.tsx` - добавлена отладочная информация

## Проблема 2: Дубли в вопросах (режим Эрудит)

### Описание проблемы:
- В режиме Эрудит (30 вопросов) повторялись одни и те же страны
- Логика `i % shuffledCountries.length` приводила к циклическим повторам

### Исправление:
- Переписана функция `generateQuestions` в `gameStore.ts`
- Теперь сначала используются все уникальные страны
- При нехватке стран избегаются повторы подряд
- Добавлены логи для отслеживания генерации вопросов

### Алгоритм исправления:
1. Если стран >= количества вопросов → берем уникальные страны
2. Если стран < количества вопросов:
   - Сначала добавляем все уникальные страны
   - Затем добавляем недостающие, избегая повторов подряд

### Файлы изменены:
- `web/src/lib/gameStore.ts` - функция `generateQuestions`
