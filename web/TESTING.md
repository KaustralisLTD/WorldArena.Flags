## Как протестировать

### 1. Откройте приложение
```
http://localhost:3000/flags/
```

### 2. Проверьте загрузку данных
- На главной странице не должно быть сообщения "Не удалось загрузить данные стран"
- Если API недоступен, используются fallback данные (15 стран)

### 3. Настройте игру
- **Регион**: Выберите "Все регионы" или конкретный регион
- **Сложность**: Легкий (10 вопросов), Средний (15), Сложный (20)
- **Режим**: Классический, На время, Выживание, Работа над ошибками

### 4. Запустите игру
- Нажмите кнопку **"Начать игру"**
- Вы будете перенаправлены на `/flags/game/`
- Начнется игровой процесс

### 5. Игровой процесс
- **Вопросы**: Показывается флаг → выбираете страну ИЛИ показывается страна → выбираете флаг
- **Таймер**: Отсчитывает время (45/30/15 сек в зависимости от сложности)
- **Счет**: Отображается в реальном времени
- **Прогресс**: Полоса прогресса показывает текущий вопрос

### 6. Завершение игры
- После всех вопросов показывается результат
- Автоматическое возвращение на главную страницу
- Результаты сохраняются в localStorage

## PWA Тестирование

### 1. Установка приложения
- В Chrome/Edge: Появится предложение "Установить приложение"
- Или кнопка "Установить приложение" в правом нижнем углу

### 2. Офлайн режим
- Установите приложение
- Отключите интернет
- Приложение должно работать с кешированными данными

### 3. Service Worker
```bash
# Проверка Service Worker
curl -I http://localhost:3000/flags/sw.js
# Должен вернуть 200 OK
```

### 4. Manifest
```bash
# Проверка Web App Manifest
curl -I http://localhost:3000/flags/manifest.json
# Должен вернуть 200 OK
```

## Возможные проблемы и решения

### Проблема: "Не удалось загрузить данные стран"
**Решение**: 
- Проверьте интернет соединение
- Приложение автоматически использует fallback данные
- Очистите кеш браузера

### Проблема: Кнопка "Начать игру" не работает
**Решение**:
- Убедитесь, что данные стран загружены
- Проверьте консоль браузера на ошибки JavaScript
- Обновите страницу

### Проблема: Страница игры показывает "Игра не найдена"
**Решение**:
- Это нормально, если вы перешли на `/game` напрямую
- Игру нужно запускать через кнопку "Начать игру" на главной странице

### Проблема: PWA не устанавливается
**Решение**:
- Используйте HTTPS (в продакшн)
- Проверьте, что Service Worker загружается
- Убедитесь, что manifest.json доступен
