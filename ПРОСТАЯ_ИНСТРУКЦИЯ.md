# 🚀 ПРОСТАЯ ИНСТРУКЦИЯ: Загрузить гимн Украины на сервер

## ⚡ Один шаг - выполните команду:

Откройте **Терминал** (Cmd+Пробел → Terminal) и выполните:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025"
./загрузить_гимн_украины.sh
```

**Всё!** Скрипт сам:
- ✅ Создаст резервную копию старого файла
- ✅ Загрузит новый правильный файл
- ✅ Покажет результат

**Если попросит пароль** - введите пароль от сервера `flags.worldarena.games` (root пользователь).

---

## ✅ После загрузки:

1. Проверьте в браузере: https://flags.worldarena.games/anthems/anthem_ua.m4a
   - Должен загрузиться файл **~1.9 MB** (а не 709 KB)
   - Если видите ошибку **403 Forbidden** - выполните:
     ```bash
     ./исправить_права_гимн_украины.sh
     ```

2. Очистите кэш приложения на iOS устройстве

3. Перезапустите приложение и проверьте гимн Украины

---

Если скрипт не работает, выполните команды по одной:

```bash

cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025"

# 2. Создайте резервную копию (введите пароль когда попросит)

# 3. Загрузите новый файл (введите пароль когда попросит)
scp anthem_ua_correct.m4a root@flags.worldarena.games:/var/www/flags.worldarena.games/anthems/anthem_ua.m4a
```
