# Гимн Украины - Инструкция по замене

## Проблема

Текущий файл `anthem_ua.m4a` на сервере является поврежденным или неполным (30 секунд, "писк" вместо реального гимна).

## Решение

Скачан официальный гимн Украины с Wikimedia Commons (исполнение U.S. Navy Band):
- ✅ Длительность: ~80 секунд (полная версия)
- ✅ Формат: AAC, стерео, 44100 Гц, 192 кбит/с
- ✅ Размер: ~1.9 MB
- ✅ Источник: Public Domain (свободное использование)

## Использование скрипта

### Автоматическое скачивание и конвертация:

```bash
./download_ukraine_anthem.sh
```

Скрипт выполнит:
1. Скачивание оригинального файла с Wikimedia Commons
2. Конвертацию в формат M4A (AAC, 192kbps)
3. Проверку результата
4. Вывод инструкций по загрузке на сервер

### Ручная загрузка на сервер

После выполнения скрипта файл `anthem_ua.m4a` будет готов к загрузке:

```bash
# Через SCP
scp anthem_ua.m4a user@flags.worldarena.games:/path/to/anthems/anthem_ua.m4a

# Или через SFTP/FTP клиент
# Загрузите файл в директорию: /path/to/anthems/anthem_ua.m4a
```

## Проверка файла

После загрузки проверьте файл:

```bash
# Проверка размера и формата
curl -I https://flags.worldarena.games/anthems/anthem_ua.m4a

# Скачивание и проверка локально
curl -o test_anthem.m4a https://flags.worldarena.games/anthems/anthem_ua.m4a
ffprobe test_anthem.m4a
```

## Требования

- `ffmpeg` (для конвертации)
- `curl` (для скачивания)
- Доступ к серверу для загрузки файла

## Файлы

- `anthem_ua_new.m4a` - новый правильный гимн (готов к использованию)
- `anthem_ua.m4a` - старый поврежденный файл (можно удалить после замены)
- `ukraine_anthem.oga` - оригинальный файл с Wikimedia Commons
- `download_ukraine_anthem.sh` - скрипт для автоматизации
