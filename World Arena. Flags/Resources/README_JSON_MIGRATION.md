# Миграция на JSON файлы

## Шаги для перехода на JSON

### 1. Экспорт данных в JSON

Добавьте временно в код (например, в `viewDidLoad` или `init`) вызов:

```swift
CountryDatabase.exportToJSON()
```

Запустите приложение один раз. JSON файлы будут созданы в Documents директории.

### 2. Добавление JSON файлов в проект

1. Скопируйте созданные файлы из Documents:
   - `countries_part1.json`
   - `countries_part2.json`
   - `countries_part3.json`

2. В Xcode:
   - Перетащите файлы в папку `Resources` (или создайте папку Resources)
   - Убедитесь, что файлы добавлены в Target Membership
   - Проверьте, что "Copy Bundle Resources" включает эти файлы

### 3. Проверка работы

После добавления JSON файлов:
- Приложение автоматически загрузит данные из JSON
- Если JSON файлы не найдены, будет использован fallback на Swift код
- Убедитесь, что данные загружаются корректно

### 4. Удаление старых файлов (опционально)

После успешной миграции можно удалить:
- `CountryDatabasePart1.swift`
- `CountryDatabasePart2.swift`
- `CountryDatabasePart3.swift`
- Extension свойства из `CountryDatabase.swift`

Но рекомендуется оставить их как резервную копию на некоторое время.

## Преимущества JSON

✅ Нет проблем с синтаксисом Swift
✅ Легче редактировать данные
✅ Можно обновлять без пересборки (если загружать динамически)
✅ Проще версионировать в Git
✅ Можно использовать внешние инструменты для редактирования
