# Конфиденциальность и данные в App Store Connect

Как в Duolingo и на скриншоте: в App Store Connect нужно заполнить два блока — **«Данные, используемые для отслеживания»** и **«Связанные с пользователем данные»**. Ниже — что у нас реально собирается и как это указать.

---

## Где что править

| Что | Где |
|-----|-----|
| **Заявление в App Store** (то, что видно на скриншоте) | **App Store Connect** → приложение → вкладка **«Конфиденциальность приложения»** (App Privacy) |
| Текст запроса доступа (например, для трекинга) | **Xcode** → таргет приложения → вкладка **Info** или файл **World-Arena--Flags-Info.plist** |
| Экран настроек приватности в приложении | **PrivacySettingsView.swift** |
| Текст политики конфиденциальности в приложении | **PrivacyPolicyView.swift** и/или сайт https://worldarena.games/privacy-policy.html |

---

## Что собирает приложение (по коду)

- **Аккаунт (если пользователь входит):** email, имя пользователя (username), токен, код друга.
- **Идентификаторы:** идентификатор пользователя на сервере; рекламные SDK (AdMob, возможно Firebase) могут использовать идентификаторы устройства в рамках своей политики.
- **Данные об использовании:** прогресс в игре, статистика (игры, точность, серии), лиги, квесты, дуэли, настройки (регионы, сложность, язык).
- **Диагностика:** при использовании Firebase/Crashlytics — краши и ошибки (если подключено).
- **Геопозиция:** не собирается (в коде нет доступа к локации).
- **Пользовательский контент:** фото/видео не собираются; данные аватара (настройки внешности) хранятся локально и при синхронизации аккаунта могут уходить на сервер — при желании можно отнести к «Другие данные».

---

## Что указать в App Store Connect

### 1. Данные, используемые для отслеживания информации

*«Следующие данные могут использоваться для отслеживания информации о пользователе в приложениях и на сайтах, принадлежащих другим компаниям».*

- Сейчас в приложении **не запрашивается** разрешение ATT (App Tracking Transparency), реклама показывается без кросс-приложенного трекинга.
- Рекомендация: указать **«Данные, используемые для отслеживания»** = **Нет** (или только те типы данных, которые вы реально будете использовать для трекинга после добавления ATT и запроса разрешения).
- Если позже добавите запрос ATT и будете использовать идентификаторы для рекламы — тогда в этом блоке нужно будет добавить соответствующие типы (например, идентификаторы).

### 2. Связанные с пользователем данные

*«Может вестись сбор следующих данных, которые связаны с личностью пользователя».*

Указывать по факту:

| Категория в App Store | Что выбрать | Пояснение |
|------------------------|-------------|-----------|
| **Контактные данные** | Email, Имя (или «Имя пользователя») | Если есть вход по email и отображаемое имя. |
| **Идентификаторы** | User ID (идентификатор пользователя) | ID на вашем сервере. При использовании рекламных/аналитических SDK можно дополнительно указать то, что описано в их документации (Device ID и т.д.). |
| **Данные об использовании** | Данные о продукте (прогресс, действия в приложении) | Игры, точность, серии, лиги, квесты, настройки. |
| **Диагностика** | Данные о крашах и производительности | Если включены Crashlytics/аналитика крашей. |
| **Другие данные** | По необходимости | Например, настройки аватара/профиля, если считаете их «связанными с пользователем» и не входящими в «использование». |
| **Геопозиция** | Не указывать | Не собирается. |
| **Пользовательский контент** | Не указывать (или уточнить при появлении UGC) | Фото/видео не собираются. |

Для каждой выбранной категории Apple дальше спросит:
- с какой целью собираются данные (например, «Функциональность приложения», «Аналитика», «Реклама»);
- связаны ли они с идентичностью (да, т.к. блок «Связанные с пользователем»);
- используются ли для трекинга (как правило, «Нет» в текущей схеме).

## Действия в Xcode / проекте

1. **World-Arena--Flags-Info.plist**  
   - Уже есть ключи для Face ID и рекламы (GADApplicationIdentifier).  
   - Если позже добавите запрос ATT (App Tracking Transparency), нужно добавить ключ **NSUserTrackingUsageDescription** с понятным текстом (например: «Чтобы показывать более подходящую рекламу»). Пример уже добавлен в plist с нейтральной формулировкой.

2. **Политика и экран настроек**  
   - Текст в **PrivacyPolicyView** и на сайте должен совпадать с тем, что вы заявляете в App Store Connect (какие данные, зачем, как хранятся).  
   - В **PrivacySettingsView** переключатели (аналитика, краши и т.д.) должны реально влиять на сбор, если вы его делаете (сейчас часть настроек только сохраняется в UserDefaults).

## Краткий чек-лист для App Store Connect

- [ ] Открыть приложение → **App Privacy**.
- [ ] **«Данные для отслеживания»**: сейчас — не используются (или добавить только при использовании ATT).
- [ ] **«Связанные с пользователем данные»**:  
  - Контактные данные (Email, Имя) — если есть аккаунт.  
  - Идентификаторы (User ID; при использовании рекламы/аналитики — по документации SDK).  
  - Данные об использовании (прогресс, действия в приложении).  
  - Диагностика (если есть краш-репорты).  
  - При необходимости — Другие данные (настройки профиля/аватара).
- [ ] Для каждого типа указать цель сбора и что не используется для трекинга (если так и есть).
- [ ] Обновить политику конфиденциальности (в приложении и на сайте), чтобы формулировки совпадали с заявлением в App Store Connect.

После этого заявление в App Store будет соответствовать скриншоту и подходу вроде Duolingo: явно указаны и «отслеживание», и «связанные с пользователем» данные.
