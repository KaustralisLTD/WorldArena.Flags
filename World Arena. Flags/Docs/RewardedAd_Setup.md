# Настройка рекламы «Видео за +3 жизни» (для чайников)

В приложении уже есть кнопка **«Смотреть видео: +3 жизни»** в алерте «Жизни закончились». Чтобы показывалась реальная реклама и пользователи получали жизни, нужно подключить Google AdMob и один раз настроить проект.

---

## Часть 1: Google AdMob (не App Store Connect)

**App Store Connect** — это для публикации приложения в Store. Реклама настраивается в **Google AdMob** — отдельный сервис.

### Шаг 1. Аккаунт AdMob

1. Откройте в браузере: **https://admob.google.com**
2. Войдите через Google-аккаунт (тот же, что для Gmail).
3. Если AdMob просит «добавить приложение» — нажмите **«Добавить приложение»**.

### Шаг 2. Добавить приложение в AdMob

1. В AdMob: **Приложения** → **Добавить приложение**.
2. Вопрос «Уже опубликовано ли приложение в App Store или Google Play?»  
   - Если приложение **уже в App Store** — выберите **Да** и укажите ссылку или название.  
   - Если **ещё не опубликовано** — выберите **Нет** и введите название приложения (например, «World Arena Flags»).
3. Укажите платформу **iOS**.
4. Нажмите **Готово**. Приложение появится в списке.

### Шаг 3. Создать рекламный блок (Rewarded)

1. В карточке вашего приложения нажмите **«Рекламные блоки»** (или **Ad units**).
2. **Добавить рекламный блок**.
3. Тип: выберите **«Вознаграждаемая»** (Rewarded).
4. Название: например, «Видео за жизни» или «Lives reward».
5. Сохраните. AdMob покажет **ID рекламного блока** — длинная строка вида:
   ```text
   ca-app-pub-XXXXXXXXXXXXXXXX/YYYYYYYYYY
   ```
6. **Скопируйте этот ID** — он понадобится в Xcode и перед релизом подставляется в код вместо тестового ID.

### Шаг 4. Узнать ID приложения AdMob (для Info.plist)

1. В AdMob откройте своё приложение.
2. В разделе **«Настройки приложения»** или в карточке приложения найдите **«Идентификатор приложения AdMob»** (App ID) — строка вида:
   ```text
   ca-app-pub-XXXXXXXXXXXXXXXX~ZZZZZZZZZZ
   ```
   (с тильдой `~`, не с `/`).
3. **Скопируйте** — его нужно прописать в настройках цели в Xcode (см. ниже).

## Часть 2: Xcode

### Шаг 5. Добавить SDK рекламы (Swift Package Manager)

1. В Xcode: **File** → **Add Package Dependencies...**
2. В поле URL вставьте:
   ```text
   https://github.com/googleads/swift-package-manager-google-mobile-ads.git
   ```
3. Нажмите **Add Package**, выберите продукт **GoogleMobileAds**, добавьте к таргету **World Arena. Flags**.
4. Дождитесь загрузки пакета.

После этого проект начнёт собираться с реальной рекламой (сейчас в коде стоит **тестовый** ID — реклама будет показываться, но это тестовые объявления Google).

### Шаг 6. Прописать App ID в проекте (Info.plist)

AdMob требует указать идентификатор приложения в Info.

1. В Xcode откройте проект **World Arena. Flags**.
2. Выберите таргет **World Arena. Flags** (не проект, а именно таргет приложения).
3. Вкладка **Info** (или **Build Settings** → искать Info.plist).
4. В разделе **Custom iOS Target Properties** нажмите **+** и добавьте ключ:
   - **Key:** `GADApplicationIdentifier`  
   - **Type:** String  
   - **Value:** ваш **App ID из AdMob** (из Шага 4), например:  
     `ca-app-pub-1234567890123456~1234567890`

Если в проекте есть отдельный файл **Info.plist**, откройте его в редакторе и добавьте туда:

```xml
<key>GADApplicationIdentifier</key>
<string>ca-app-pub-XXXXXXXXXXXXXXXX~ZZZZZZZZZZ</string>
```

(подставьте свой App ID с тильдой `~`).

### Шаг 7. Подставить свой рекламный блок перед релизом

Сейчас в коде используется **тестовый** ID рекламы (так разрешено правилами AdMob для разработки). Перед выкладкой в App Store нужно перейти на свой блок.

**Вариант А (рекомендуется):** при старте приложения вызвать:

```swift
RewardedAdService.shared.configure(adUnitID: "ca-app-pub-XXXXXXXXXXXXXXXX/YYYYYYYYYY")
```

например в `FlagsWorldApp.swift` в `.onAppear` (можно брать ID из конфига или удалённой настройки).

**Вариант Б:** в файле `Services/RewardedAdService.swift` заменить тестовый ID `ca-app-pub-3940256099942544/1712485313` на свой (строка с `adUnitID`). Либо сохранять свой ID в `UserDefaults` по ключу `admob.rewarded.lives.unitId` и читать его в `loadAd()` (логика уже предусмотрена в `configure(adUnitID:)`).

## Часть 3: App Store Connect (что сделать из-за рекламы)

Здесь ничего «оптимизировать под рекламу» не нужно. Нужно только корректно отразить, что в приложении есть реклама.

1. **App Store Connect** → ваше приложение → **App Information** (или страница приложения).
2. В блоке **App Privacy** (или в анкете конфиденциальности) укажите, что приложение **показывает рекламу** (или использует рекламный идентификатор), если такая графа есть.
3. При отправке на модерацию в разделе про **рекламу** можно кратко написать: «Rewarded video ad to earn extra lives» / «Награждаемое видео за дополнительные жизни».
4. В карточке приложения в Store может быть пункт **«Содержит рекламу»** — он часто проставляется автоматически, если вы указали использование рекламы в настройках приложения.

Никаких специальных «оптимизаций» с стороны App Store Connect для AdMob не требуется: AdMob и App Store — разные системы, связь только через то, что вы честно указываете наличие рекламы в приложении.

## Краткий чек-лист

- [ ] Зарегистрироваться в AdMob (admob.google.com).
- [ ] Добавить приложение в AdMob, создать рекламный блок типа **Вознаграждаемая** (Rewarded).
- [ ] Скопировать **App ID** (с `~`) и **ID рекламного блока** (с `/`).
- [ ] В Xcode: добавить пакет `swift-package-manager-google-mobile-ads`, продукт GoogleMobileAds.
- [ ] В настройках таргета (Info) добавить `GADApplicationIdentifier` = App ID из AdMob.
- [ ] Перед релизом: подставить свой ID рекламного блока (через `configure(adUnitID:)` или в коде).
- [ ] В App Store Connect указать, что приложение содержит рекламу, если спрашивают.

После этого кнопка «Смотреть видео: +3 жизни» будет показывать рекламу и начислять 3 жизни после просмотра.
