# Настройка Mailgun для сброса пароля (пошагово)

Письма с кодом сброса пароля отправляются через Mailgun. Если Mailgun не настроен, код пишется только в лог сервера (удобно для разработки).

---

## Шаг 1. Войти в Mailgun

1. Откройте [mailgun.com](https://www.mailgun.com) и войдите в аккаунт (ты уже зарегистрирован).
2. Попадёте в панель (Dashboard).

---

## Шаг 2. Узнать домен отправителя

1. В левом меню: **Sending** → **Domains** (или **Domain**).
2. Увидите список доменов. Есть **Sandbox domain** вида `sandboxXXXXXXXX.mailgun.org` — для теста его достаточно.
3. **Скопируйте** этот домен целиком (например `sandbox123abc.mailgun.org`) — это ваш **MAILGUN_DOMAIN**.

Если добавляете свой домен — потом нужно будет прописать DNS-записи, которые покажет Mailgun. Для начала хватит Sandbox.

---

## Шаг 3. Взять API-ключ

1. В левом меню: **Sending** → **API Keys** (или **Settings** → **API Keys** / **API Security**).
2. Найдите **Private API key** (длинная строка, часто начинается с `key-...`).
3. Нажмите **Reveal** / **Show** и **скопируйте** ключ.  
   Это ваш **MAILGUN_API_KEY**. Никому не показывайте и не загружайте в репозиторий.

---

## Шаг 4. Узнать регион (EU или US)

1. Вверху страницы Mailgun часто указан регион: **EU** или **US**.
2. Если **EU** — нужна переменная **MAILGUN_EU=true** (иначе письма пойдут не в тот дата-центр и могут не отправляться).

---

## Шаг 5. Создать файл с настройками на сервере

1. Откройте папку **Server** проекта (рядом с `server.js`).
2. Создайте файл **`.env`** (точка в начале, без расширения).
3. Вставьте в него (подставьте свои значения):

```env
MAILGUN_API_KEY=ваш_private_api_key_из_шага_3
MAILGUN_DOMAIN=sandboxXXXXXXXX.mailgun.org
MAILGUN_EU=true
```

- Замените `ваш_private_api_key_из_шага_3` на ключ из шага 3.  
- Замените `sandboxXXXXXXXX.mailgun.org` на домен из шага 2.  
- Если у вас регион **US**, напишите `MAILGUN_EU=false` или просто удалите строку `MAILGUN_EU`.

Опционально можно задать адрес отправителя:

```env
MAILGUN_FROM=World Arena <noreply@ваш-домен.mailgun.org>
```

Иначе будет использоваться `noreply@MAILGUN_DOMAIN`.

4. Сохраните файл.  
5. Добавьте в корневой **.gitignore** строку `Server/.env`, чтобы ключ не попал в git.

---

## Шаг 6. Установить зависимость и запустить сервер

1. В терминале перейдите в папку **Server**:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/Server"
```

2. Установите пакет для отправки писем:

```bash
npm install
```

(В проект уже добавлен `form-data`, он установится вместе с остальными зависимостями.)

3. В проекте уже подключён `dotenv`: при запуске сервера переменные из **Server/.env** подхватываются автоматически. Просто запустите сервер как обычно:

```bash
npm start
```

или

```bash
node server.js
```

---

## Шаг 7. Передать переменные в процесс (если не используете dotenv)

Если не ставите `dotenv`, перед запуском в том же терминале выполните (подставьте свои значения):

**macOS / Linux:**

```bash
export MAILGUN_API_KEY=ваш_ключ
export MAILGUN_DOMAIN=sandboxXXXXXXXX.mailgun.org
export MAILGUN_EU=true
node server.js
```

**Windows (cmd):**

```cmd
set MAILGUN_API_KEY=ваш_ключ
set MAILGUN_DOMAIN=sandboxXXXXXXXX.mailgun.org
set MAILGUN_EU=true
node server.js
```

---

## Шаг 7. Проверить отправку

1. В приложении на экране сброса пароля введите **email**, который привязан к аккаунту в приложении.
2. Нажмите «Отправить код» / запрос сброса.
3. Проверьте почту (и папку «Спам») — должно прийти письмо с кодом.
4. Введите этот код и новый пароль в приложении и завершите сброс.

Если письмо не пришло:

- Проверьте, что **MAILGUN_API_KEY** и **MAILGUN_DOMAIN** заданы и сервер перезапущен после их добавления.
- Для Sandbox домена Mailgun разрешает отправку только на **заранее добавленный** адрес. В Mailgun: **Sending** → **Domains** → ваш домен → **Authorized Recipients** — добавьте свой тестовый email.
- Посмотрите лог сервера: при ошибке Mailgun там будет строка `[auth/reset-password] mailgun ...`.
