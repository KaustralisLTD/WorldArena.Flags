# Разбор логов консоли приложения

Кратко: что означают сообщения в консоли Xcode и можно ли от них избавиться.

---

## Исправлено в проекте

### 1. **50 required SKAdNetwork identifier(s) missing from Info.plist**
- **Что:** Google AdMob требует указать SKAdNetwork ID в Info.plist для трекинга конверсий (SKAdNetwork).
- **Зачем:** Нужно для атрибуции рекламы и отчётности в AdMob.
- **Решение:** В `World-Arena--Flags-Info.plist` добавлен ключ `SKAdNetworkItems` со списком из 50 идентификаторов (Google + партнёры по [документации Google](https://developers.google.com/admob/ios/3p-skadnetworks)). После пересборки это предупреждение в логах должно пропасть.

---

## Системные / симулятор — убрать нельзя

Эти сообщения идут от iOS, WebKit или симулятора. На работу приложения не влияют, из кода приложения их убрать нельзя.

### 2. **WebContent: Unable to hide query parameters from script (missing data)**
- **Что:** WebKit (WKWebView) не может скрыть query-параметры в URL при запросе скрипта (приватность).
- **Откуда:** Часто из рекламных/внешних скриптов (в т.ч. Google) внутри WebView.
- **Решение:** Игнорировать. Либо не использовать WebView для страниц с такими скриптами, если они не нужны.

### 3. **nw_connection_copy_connected_local_endpoint_block_invoke [C*] Connection has no local endpoint**
- **Что:** Network.framework сообщает, что у соединения ещё нет локального endpoint (например, во время установки соединения).
- **Откуда:** Внутренняя логика сети, часто в симуляторе.
- **Решение:** Игнорировать. На устройстве обычно реже.

### 4. **<<< timebase >>> signalled err=-12753**
- **Что:** Ошибка системного timebase (таймеры/синхронизация).
- **Откуда:** Симулятор / системный слой.
- **Решение:** Игнорировать.

### 5. **HALC_ProxyIOContext::IOWorkLoop: skipping cycle due to overload**
- **Что:** Аудио HAL пропускает цикл из‑за перегрузки.
- **Откуда:** Симулятор при нагрузке на CPU/аудио.
- **Решение:** Игнорировать. На устройстве при нормальной нагрузке обычно не мешает.

### 6. **(Fig) signalled err=-12900**
- **Что:** Ошибка медиа-фреймворка (Fig — внутренний компонент Apple).
- **Откуда:** Симулятор/медиа-стек.
- **Решение:** Игнорировать.

### 7. **LoudnessManager.mm: unable to open stream / IsHardwareSupported: no plist loaded**
- **Что:** Системный Loudness Manager не находит свой plist (управление громкостью).
- **Откуда:** В симуляторе нет полного набора «железных» конфигов.
- **Решение:** Игнорировать. Типично только для симулятора.

### 8. **could not read user kCFPreferencesCurrentUser uid/gid**
- **Что:** Симулятор не может прочитать uid/gid текущего пользователя для настроек.
- **Откуда:** Окружение симулятора.
- **Решение:** Игнорировать.

### 9. **file does not exist... clearing ... com.apple.CoreMotion.plist**
- **Что:** В симуляторе нет файла настроек CoreMotion (акселерометр и т.д.).
- **Откуда:** Симулятор не эмулирует полный набор датчиков.
- **Решение:** Игнорировать.

### 10. **WebProcess::updateFreezerStatus**
- **Что:** Внутреннее состояние WebKit (заморозка процесса).
- **Откуда:** WebKit.
- **Решение:** Игнорировать.

---

## Как меньше шума в консоли

1. **Фильтр в Xcode:** В консоли поставить фильтр по процессу (например, только ваш таргет) или скрывать системные сообщения.
2. **Проверка на устройстве:** Большая часть перечисленных логов характерна для симулятора; на реальном устройстве их часто нет или меньше.
3. **SKAdNetwork:** Уже добавлен в Info.plist — предупреждение от Google после пересборки должно исчезнуть.

Итог: единственное, что можно было «починить» в проекте — это предупреждение про SKAdNetwork (добавлены идентификаторы в Info.plist). Остальные сообщения — системные/симуляторные, их не убирают из кода приложения.
