## Что охватывает текст

- **Режим Дуэли** — вызов друга, одна и та же игра, сравнение результатов.
- **F-Bucks** — валюта за идеальную игру, дуэли, подарки.
- **Ежедневные квесты и подарки** — прогресс, награды (XP, F-Bucks).
- **Лиги** — рейтинг, продвижение по рангам.
- **Режимы игры** — Классика, На время, Выживание.
- **Друзья и серии** — добавление друзей, отслеживание серий дней.

Где вносить: **App Store Connect** → ваше приложение → **Версия приложения** (или страница приложения) → блок **«Промо-текст» (Promotional Text)**.

## Описание для заявки (только для команды App Store)

**Когда нужно:** при добавлении описания в заявке (например, рекламная программа Apple). Текст виден только команде App Store.

### English (рекомендуется для заявок)

```
World Arena Flags is an educational quiz game for learning world flags and countries. Players see a flag and choose the correct country name from multiple options. The app includes several game modes: Classic (set number of questions), Time Challenge, Survival (until first mistake), and Duel (challenge a friend to the same quiz; results are compared). Users earn in-game currency (F-Bucks) for perfect games and duel wins, complete daily quests and gifts, climb leagues (Bronze to Master), add friends, and track daily streaks. Content is available by region (e.g. Europe, Asia, Americas). Optional premium subscription adds unlimited lives, Learning section, Erudite difficulty, and My Mistakes mode.
```

### Русский (если форма принимает русский)

```
World Arena Flags — образовательная викторина для изучения флагов и стран мира. Игрок видит флаг и выбирает правильное название страны из вариантов. Режимы: Классика, На время, Выживание и Дуэль (вызов друга на один и тот же квиз с сравнением результатов). Начисляется внутриигровая валюта F-Bucks за идеальную игру и победы в дуэлях, есть ежедневные квесты и подарки, лиги (от Бронзы до Мастера), друзья и серии дней. Контент по регионам (Европа, Азия, Америки и др.). По подписке — безлимитные жизни, раздел Обучения, сложность Эрудит и режим «Мои ошибки».
```

## Полезные сведения — что делает приложение уникальным (Helpful information)

**Когда нужно:** поле «Расскажите, что делает ваше приложение уникальным» (нестандартная помощь пользователям / инклюзивность). Ответ на английском.

### English

```
World Arena Flags stands out by turning flag learning into a fair, social competition. In Duel mode, two friends get the exact same quiz (same flags, same order), so the comparison is genuine and motivating. Players earn F-Bucks for perfect games and duel wins, climb leagues from Bronze to Master, and keep daily streaks with optional friend nudges. Learning is personalized: play by region (e.g. Europe or Asia), revisit your weak spots in “My Mistakes,” and use the Learning section to study before quizzing. The app supports Dynamic Type and readable layouts so more users can play comfortably. We focus on one clear goal — helping people learn world flags through short, repeatable sessions and friendly competition — without ads during gameplay.
```
