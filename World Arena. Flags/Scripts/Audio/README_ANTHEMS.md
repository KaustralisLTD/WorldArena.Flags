# Система гимнов стран

## Обзор

Система загрузки и воспроизведения гимнов стран в приложении Flags World. Гимны загружаются с сервера в формате M4A и кэшируются локально для быстрого доступа.

## Архитектура

### 1. Загрузка гимнов
- **Источники**: Wikimedia Commons, Internet Archive (общественное достояние)
- **Формат**: M4A (AAC, 192kbps, 44.1kHz)
- **Сервер**: `https://flags.worldarena.games/anthems/`

### 2. Кэширование
- **Локальное хранилище**: `~/Library/Caches/` (iOS)
- **Автоматическая очистка**: Система iOS
- **Проверка обновлений**: При каждом воспроизведении

### 3. Воспроизведение
- **AudioManager**: Центральный класс для управления аудио
- **AVAudioPlayer**: Нативный iOS плеер
- **Прогресс-бар**: Отображение времени воспроизведения

## Использование

### 1. Загрузка гимнов

```bash
# Установить зависимости
pip install requests

# Запустить загрузку
cd "World Arena. Flags/Resources/Audio"
python3 download_real_anthems.py
```

### 2. Загрузка на сервер

```bash
# Настроить SSH ключи для доступа к серверу
# Запустить загрузку
chmod +x upload_to_server.sh
./upload_to_server.sh
```

### 3. В приложении

```swift
// Воспроизведение гимна
AudioManager.shared.playAnthem(for: "ru")

// Остановка
AudioManager.shared.stopAudio()

// Пауза/возобновление
AudioManager.shared.pauseAudio()
AudioManager.shared.resumeAudio()
```

## Технические детали

### Форматы файлов
- **Входной**: OGG (Wikimedia Commons)
- **Промежуточный**: WAV (конвертация)
- **Финальный**: M4A (AAC кодек)

### Качество аудио
- **Битрейт**: 192 kbps
- **Частота**: 44.1 kHz
- **Каналы**: Стерео
- **Длительность**: 1-3 минуты

### Размеры файлов
- **Средний размер**: 2-5 MB
- **Общий объем**: ~100 MB (40 стран)
