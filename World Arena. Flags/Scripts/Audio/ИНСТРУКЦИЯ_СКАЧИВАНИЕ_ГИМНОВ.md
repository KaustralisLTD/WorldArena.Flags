# 📖 Инструкция: Как скачать и загрузить все гимны на сервер

## 🎯 Что нужно сделать

Скачать недостающие аудио файлы гимнов (~142 файла) и загрузить их на сервер `flags.worldarena.games`.

---

## 📋 Требования

Перед началом убедитесь, что у вас установлены:

1. **Python 3** (обычно уже установлен на Mac)
   ```bash
   python3 --version
   ```

2. **yt-dlp** (для скачивания с YouTube)
   ```bash
   # Установка через Homebrew
   brew install yt-dlp
   
   # Или через pip
   pip3 install yt-dlp
   ```

3. **ffmpeg** (для конвертации аудио)
   ```bash
   # Установка через Homebrew
   brew install ffmpeg
   ```

4. **SSH доступ к серверу** (для загрузки файлов)
   - Убедитесь, что можете подключиться: `ssh root@157.230.11.51`
   - Если требуется пароль, скрипт его запросит

---

## 🚀 Пошаговая инструкция

### Шаг 1: Перейдите в папку со скриптами

Откройте Terminal (Терминал) и перейдите в папку со скриптами:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"
```

### Шаг 2: Сделайте скрипты исполняемыми

```bash
chmod +x download_all_missing_anthems.py
chmod +x upload_all_anthems_to_server.sh
```

### Шаг 3: Запустите скрипт скачивания

```bash
python3 download_all_missing_anthems.py
```

**Что делает скрипт:**
- ✅ Проверяет какие гимны уже есть на сервере
- ✅ Определяет какие нужно скачать
- ✅ Скачивает недостающие гимны с YouTube
- ✅ Конвертирует их в формат m4a
- ✅ Сохраняет в папку `real_anthems_complete/`

**⏱️ Время выполнения:** ~2-3 часа (зависит от скорости интернета)

**💡 Совет:** Скрипт делает паузы между скачиваниями (3-6 секунд), чтобы избежать блокировок YouTube. Не прерывайте процесс!

### Шаг 4: Проверьте скачанные файлы

После завершения скрипта проверьте папку:

```bash
ls -lh real_anthems_complete/
```

Должны быть файлы вида `anthem_XX.m4a` (например, `anthem_al.m4a`, `anthem_ad.m4a` и т.д.)

### Шаг 5: Загрузите файлы на сервер

```bash
./upload_all_anthems_to_server.sh
```

**Что делает скрипт:**
- ✅ Проверяет наличие файлов
- ✅ Подключается к серверу
- ✅ Загружает все файлы через rsync
- ✅ Настраивает права доступа
- ✅ Показывает статистику

**⏱️ Время выполнения:** ~10-30 минут (зависит от скорости интернета)

## ⚠️ Возможные проблемы и решения

### Проблема 1: "yt-dlp: command not found"

**Решение:**
```bash
brew install yt-dlp
# или
pip3 install yt-dlp
```

### Проблема 2: "ffmpeg: command not found"

**Решение:**
```bash
brew install ffmpeg
```

### Проблема 3: Ошибка подключения к серверу

**Решение:**
- Проверьте доступность сервера: `ping 157.230.11.51`
- Проверьте SSH подключение: `ssh root@157.230.11.51`
- Убедитесь, что у вас есть доступ к серверу

### Проблема 4: YouTube блокирует запросы (429 ошибка)

**Решение:**
- Скрипт автоматически делает паузы между запросами
- Если проблема повторяется, увеличьте паузы в скрипте (строка с `wait = 3 + (i % 4)`)

### Проблема 5: Файл не найден для какой-то страны

**Решение:**
- Скрипт пропустит эту страну и продолжит работу
- Можно попробовать скачать вручную позже
- Или добавить другой поисковый запрос в словарь `SEARCH_QUERIES`

## 💡 Полезные команды

```bash
ls -1 real_anthems_complete/anthem_*.m4a | wc -l
```

### Посмотреть размер папки:
```bash
du -sh real_anthems_complete/
```

```bash
ls -lh real_anthems_complete/anthem_al.m4a
```

### Удалить все скачанные файлы (если нужно начать заново):
```bash
rm -rf real_anthems_complete/
```

## 📝 Примечания

1. **Формат файлов:** Все файлы сохраняются в формате `.m4a` (AAC кодек, 192 kbps)
2. **Размер файлов:** Обычно 1-5 MB на файл
3. **Имена файлов:** `anthem_{код_страны}.m4a` (например, `anthem_al.m4a` для Албании)
4. **Сервер:** Файлы загружаются на `https://flags.worldarena.games/anthems/`
5. **Автоматическая проверка:** Скрипт автоматически проверяет какие гимны уже есть на сервере и скачивает только недостающие
