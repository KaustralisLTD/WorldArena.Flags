# 🎵 Скрипты для работы с гимнами стран

Эта папка содержит скрипты для загрузки и настройки системы гимнов стран.

## 📁 Содержимое

- `setup_anthems.sh` - 🚀 Главный скрипт настройки
- `download_real_anthems.py` - 📥 Загрузка гимнов из сети
- `upload_to_server.sh` - 🌐 Загрузка на сервер
- `README_ANTHEMS.md` - 📚 Подробная документация
- `QUICK_START.md` - ⚡ Быстрый старт

## 🚀 Использование

```bash
# Перейти в папку скриптов
cd "World Arena. Flags/Scripts/Audio"

# Запустить автоматическую настройку
./setup_anthems.sh
```
