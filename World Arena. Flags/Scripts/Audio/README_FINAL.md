## 🔄 Обновление гимнов:

### Для добавления новых стран:
1. Отредактируйте `COUNTRIES` в `create_test_anthems.py`
2. Запустите: `python3 create_test_anthems.py`
3. Запустите: `./upload_to_server.sh`

### Для замены на реальные гимны:
1. Подготовьте M4A файлы в формате 192kbps AAC
2. Переименуйте в формат `anthem_XX.m4a` (XX - код страны)
3. Загрузите в папку `real_anthems/`
4. Запустите: `./upload_to_server.sh`
