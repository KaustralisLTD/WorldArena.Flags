# 🎵 Настройка реальных гимнов стран

## Обзор

Этот документ описывает процесс загрузки и размещения реальных аудио файлов гимнов для всех 51 страны в приложении Flags World.

## 📋 Требования

### Программное обеспечение
- Python 3.7+
- ffmpeg (для конвертации аудио)
- requests (Python библиотека)

### Установка зависимостей

```bash
# Установка ffmpeg (macOS)
brew install ffmpeg

# Установка Python библиотек
pip3 install requests
```

## 🚀 Быстрый старт

### 1. Загрузка гимнов

```bash
cd "World Arena. Flags/Scripts/Audio"
python3 download_all_anthems.py
```

Скрипт:
- Загрузит гимны из Wikimedia Commons для всех 51 страны
- Конвертирует их в формат M4A (AAC, 192kbps)
- Сохранит в папку `real_anthems_all/`
- Создаст манифест `manifest.json` со списком всех файлов

### 2. Проверка результатов

После завершения проверьте:
- Количество загруженных файлов (должно быть 51)
- Размер файлов (каждый ~2-5 MB)
- Манифест `manifest.json`

### 3. Загрузка на сервер

```bash
# Настроить SSH доступ к серверу
# Затем загрузить файлы
./upload_to_server.sh
```

Или вручную через SCP:
```bash
scp real_anthems_all/*.m4a user@server:/var/www/flags.worldarena.games/anthems/
```

## 🔧 Технические характеристики

### Формат аудио
- **Контейнер**: M4A
- **Кодек**: AAC
- **Битрейт**: 192 kbps
- **Частота дискретизации**: 44.1 kHz
- **Каналы**: Стерео
- **Длительность**: 1-3 минуты

### Размеры файлов
- **Средний размер**: 2-5 MB
- **Общий объем**: ~150-200 MB (51 страна)
- **Кэш**: Автоматическое управление iOS

## 📱 Использование в приложении

Приложение автоматически:
1. Проверяет наличие файла в локальном кэше
2. Если нет - загружает с сервера `https://flags.worldarena.games/anthems/anthem_{code}.m4a`
3. Сохраняет в кэш для быстрого доступа
4. Воспроизводит через `AVAudioPlayer`

### Пример использования

```swift
// Воспроизвести гимн Польши
AudioManager.shared.playAnthem(for: "pl")

// Проверить состояние
if audioManager.isDownloading {
    ProgressView()
}

if audioManager.isPlaying {
    Button("Пауза") {
        audioManager.pauseAudio()
    }
}
```

## 🔄 Процесс работы

### 1. Запрос гимна
```swift
AudioManager.shared.playAnthem(for: "pl")
```

### 2. Проверка кэша
- Ищет `anthem_pl.m4a` в локальном кэше
- Проверяет размер файла (>10KB)
- Если найден - воспроизводит

### 3. Загрузка с сервера
- Формирует URL: `https://flags.worldarena.games/anthems/anthem_pl.m4a`
- Загружает через HTTPS
- Проверяет размер и формат
- Сохраняет в кэш

### 4. Воспроизведение
- Создает `AVAudioPlayer`
- Настраивает прогресс-бар
- Запускает воспроизведение

### 5. Fallback
- При ошибках включает симуляцию
- Логирует проблемы
- Показывает статус пользователю

## 🛠️ Разработка

### Добавление новой страны

1. Добавить URL в `ANTHEM_SOURCES` в `download_all_anthems.py`
2. Запустить скрипт загрузки
3. Загрузить файл на сервер
4. Обновить манифест

### Обновление существующего гимна

1. Заменить файл в `real_anthems_all/`
2. Загрузить на сервер (перезаписать)
3. Очистить локальный кэш в приложении (опционально)

### Отладка

```bash
# Проверить наличие файла на сервере
curl -I https://flags.worldarena.games/anthems/anthem_pl.m4a

# Проверить размер файла
curl -I https://flags.worldarena.games/anthems/anthem_pl.m4a | grep Content-Length

# Скачать файл для проверки
curl -O https://flags.worldarena.games/anthems/anthem_pl.m4a
```

## 🆘 Решение проблем

### Файл не загружается
1. Проверить интернет соединение
2. Проверить доступность сервера: `curl -I https://flags.worldarena.games/anthems/test.m4a`
3. Проверить наличие файла на сервере
4. Очистить кэш и повторить

### Ошибка воспроизведения
1. Очистить локальный кэш: `AudioManager.shared.clearCache()`
2. Проверить формат файла (должен быть M4A)
3. Проверить целостность файла на сервере

### Медленная загрузка
1. Проверить скорость интернета
2. Использовать кэш (файлы загружаются один раз)
3. Оптимизировать размер файлов на сервере
