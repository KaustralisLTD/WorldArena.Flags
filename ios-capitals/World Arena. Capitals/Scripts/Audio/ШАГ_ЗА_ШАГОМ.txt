ВСЕ ДЕЙСТВИЯ ВЫПОЛНЯЮТСЯ НА МАК (локально), кроме проверки

═══════════════════════════════════════════════════════════════
ШАГ 1: УСТАНОВИТЬ ПРОГРАММЫ НА МАК
═══════════════════════════════════════════════════════════════

1. Откройте Терминал (Программы → Утилиты → Терминал)

2. Установите ffmpeg (обязательно):
   Скопируйте и вставьте:
   
   brew install ffmpeg
   
   Нажмите Enter и подождите (2-5 минут)

3. Установите yt-dlp (рекомендуется):
   
   brew install yt-dlp
   
   Или:
   
   pip3 install yt-dlp

═══════════════════════════════════════════════════════════════
ШАГ 2: ЗАГРУЗИТЬ ГИМНЫ НА МАК
═══════════════════════════════════════════════════════════════

1. Перейдите в папку со скриптами:
   
   cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"

2. Запустите скрипт загрузки:
   
   python3 download_real_anthems_complete.py

3. Подождите 20-40 минут (скрипт загрузит 51 файл)

4. Проверьте результат:
   
   ls real_anthems_complete/ | wc -l
   
   Должно показать примерно 51

═══════════════════════════════════════════════════════════════
ШАГ 3: ЗАГРУЗИТЬ ФАЙЛЫ НА СЕРВЕР
═══════════════════════════════════════════════════════════════

1. Убедитесь что вы в папке Scripts/Audio:
   
   pwd
   
   Должно показать: .../Scripts/Audio

2. Запустите скрипт загрузки на сервер:
   
   ./upload_anthems_to_server.sh

3. Когда спросит подтверждение - введите: y

4. Если попросит пароль - введите пароль root от сервера

5. Подождите 5-10 минут (загрузка файлов)

═══════════════════════════════════════════════════════════════
ШАГ 4: ПРОВЕРИТЬ РЕЗУЛЬТАТ
═══════════════════════════════════════════════════════════════

1. Проверьте файлы на сервере:
   
   python3 check_server_anthems.py
   
   Должно показать: ✅ Найдено файлов: 51/51

2. Готово! Теперь в приложении будут реальные гимны!

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════════

Проблема: "brew: command not found"
Решение: Установите Homebrew:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Проблема: "ffmpeg не найден"
Решение: brew install ffmpeg

Проблема: Скрипт загружает долго
Решение: Это нормально! Подождите 20-40 минут

Проблема: Не могу подключиться к серверу
Решение: Проверьте SSH:
ssh root@157.230.11.51
