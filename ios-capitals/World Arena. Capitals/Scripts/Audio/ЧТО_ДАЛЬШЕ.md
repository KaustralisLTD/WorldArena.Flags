## 🆘 Если что-то не работает

1. **Гимн не загружается:**
   - Проверьте интернет соединение
   - Проверьте доступность сервера: `curl -I https://flags.worldarena.games/anthems/anthem_us.m4a`
   - Очистите кэш в приложении (если есть такая опция)

2. **Ошибка сборки:**
   - Убедитесь что удалили папки с гимнами из проекта
   - Очистите Build Folder (Shift+Cmd+K)
   - Пересоберите проект

3. **Файлы не на сервере:**
   - Проверьте: `python3 check_server_anthems.py`
   - Если файлов нет - загрузите снова: `./upload_anthems_to_server.sh`
