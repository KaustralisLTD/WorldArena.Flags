# 🔧 Исправление проблемы с загрузкой гимнов

## Проблема

При запуске скрипта возникают ошибки:
- `HTTP Error 429: Too many requests` - Wikimedia блокирует массовые запросы
- `HTTP Error 404: Not Found` - некоторые URL неверны

## Решение

Скрипт обновлен для использования **YouTube как основного источника** вместо Wikimedia Commons.

### Что изменилось:

1. ✅ **YouTube стал основным источником** - загружает гимны через yt-dlp
2. ✅ **Увеличены задержки** между запросами (2-4 секунды)
3. ✅ **Добавлена обработка ошибок** с повторными попытками для Wikimedia
4. ✅ **Улучшена загрузка с YouTube** - более надежная обработка файлов

## Что нужно сделать

### 1. Убедитесь что yt-dlp установлен:

```bash
brew install yt-dlp
```

Или:
```bash
pip3 install yt-dlp
```

Проверка:
```bash
yt-dlp --version
```

### 2. Запустите обновленный скрипт:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"
python3 download_real_anthems_complete.py
```

### 3. Что произойдет:

- Скрипт будет загружать гимны с **YouTube** (основной источник)
- Если YouTube не найдет - попробует **Wikimedia Commons** (резервный)
- Между запросами будет пауза 2-4 секунды
- Загрузка займет **30-60 минут** (зависит от скорости интернета)

## Важно

- **yt-dlp обязателен** для работы скрипта
- Загрузка с YouTube может занять больше времени
- Некоторые гимны могут быть не найдены - это нормально, скрипт попробует альтернативные источники

## Если все еще не работает

1. Проверьте что yt-dlp установлен: `yt-dlp --version`
2. Проверьте интернет соединение
3. Попробуйте запустить скрипт еще раз (он пропустит уже загруженные файлы)
