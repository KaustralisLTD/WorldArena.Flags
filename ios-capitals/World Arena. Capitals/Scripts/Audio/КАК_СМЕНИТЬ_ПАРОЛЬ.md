# 🔐 Как сменить пароль root на сервере

## Проблема

После сброса пароля система требует его изменить, но через обычный SSH это не работает без TTY.

## Решение

### Способ 1: Через SSH с принудительным TTY (рекомендуется)

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"
./СМЕНИТЬ_ПАРОЛЬ.sh
```

Или вручную:
```bash
ssh -t root@157.230.11.51 "passwd"
```

**Что произойдет:**
1. Подключитесь к серверу с принудительным TTY
2. Система попросит ввести текущий пароль (тот что вы сбросили)
3. Затем попросит ввести новый пароль дважды
4. После этого пароль будет изменен

### Способ 2: Через DigitalOcean Console (если способ 1 не работает)

1. Зайдите в панель DigitalOcean: https://cloud.digitalocean.com
2. Найдите ваш дроплет (сервер 157.230.11.51)
3. Нажмите на три точки (⋮) рядом с сервером
4. Выберите **"Access"** → **"Launch Droplet Console"**
5. В консоли выполните:
   ```bash
   passwd
   ```
6. Введите новый пароль дважды

### Способ 3: Через DigitalOcean Reset Root Password

1. Зайдите в панель DigitalOcean
2. Найдите ваш дроплет
3. Нажмите **"Access"** → **"Reset Root Password"**
4. DigitalOcean сгенерирует новый пароль
5. Сохраните пароль
6. Войдите через консоль и сразу смените пароль:
   ```bash
   passwd
   ```

## После смены пароля

После успешной смены пароля можно загружать гимны:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"
./upload_anthems_to_server.sh
```

## Важно

- Новый пароль должен быть надежным (минимум 8 символов, буквы, цифры, символы)
- Сохраните пароль в безопасном месте
- После смены пароля можно использовать его для всех SSH подключений
