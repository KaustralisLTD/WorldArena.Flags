# 🎵 Пошаговая инструкция: Загрузка реальных гимнов

## Что нужно сделать

1. **На Mac** - установить программы и загрузить гимны
2. **На Mac** - загрузить файлы на сервер
3. **Готово!** - приложение будет использовать реальные гимны

---

## ШАГ 1: На Mac - Установить программы

Откройте **Терминал** на Mac (Программы → Утилиты → Терминал)

### 1.1. Установить ffmpeg (обязательно)

Скопируйте и вставьте эту команду, нажмите Enter:

```bash
brew install ffmpeg
```

Подождите, пока установится (может занять 2-5 минут).

**Проверка:**
```bash
ffmpeg -version
```

Должно показать версию ffmpeg. Если ошибка - напишите мне.

### 1.2. Установить yt-dlp (опционально, но рекомендуется)

```bash
brew install yt-dlp
```

Или через pip:
```bash
pip3 install yt-dlp
```

**Проверка:**
```bash
yt-dlp --version
```

## ШАГ 2: На Mac - Загрузить реальные гимны

### 2.1. Перейти в папку со скриптами

Скопируйте и вставьте:

```bash
cd "/Volumes/spilberg/3.Work/9.iOS/Flags.World 06.04.2025/World Arena. Flags/Scripts/Audio"
```

Нажмите Enter.

### 2.2. Запустить скрипт загрузки

```bash
python3 download_real_anthems_complete.py
```

**Что произойдет:**
- Скрипт начнет загружать гимны из интернета
- Для каждой страны будет показывать прогресс
- Это займет **15-30 минут** (зависит от скорости интернета)
- Файлы сохранятся в папку `real_anthems_complete/`

**Пример вывода:**
```
🎵 Загрузка РЕАЛЬНЫХ аудио файлов гимнов стран

📋 Всего стран для загрузки: 51

[1/51] Обрабатываю AT...
📥 Загружаю из Wikimedia Commons...
✅ Загружено 234.5 KB
🔄 Конвертирую в M4A...
✅ Конвертировано: 0.45 MB
```

**Если видите ошибки:**
- "ffmpeg не найден" → вернитесь к ШАГ 1.1
- "Ошибка загрузки" → проверьте интернет, попробуйте еще раз

### 2.3. Проверить результат

После завершения проверьте:

```bash
ls -lh real_anthems_complete/ | grep anthem_ | wc -l
```

Должно показать **51** (или близко к этому числу).

Также проверьте размер папки:

```bash
du -sh real_anthems_complete/
```

Должно быть примерно **150-200 MB**.

## ШАГ 3: На Mac - Загрузить файлы на сервер

### 3.1. Открыть скрипт загрузки

```bash
nano upload_anthems_to_server.sh
```

Или откройте файл в любом текстовом редакторе.

### 3.2. Проверить настройки

Убедитесь что в файле указано:

```bash
SERVER_USER="root"
SERVER_HOST="157.230.11.51"
SERVER_PATH="/var/www/flags.worldarena.games/anthems"
LOCAL_DIR="real_anthems_complete"
```

Если все правильно - закройте редактор (в nano: Ctrl+X, потом Y, потом Enter).

### 3.3. Запустить загрузку на сервер

```bash
./upload_anthems_to_server.sh
```

**Что произойдет:**
- Скрипт спросит подтверждение: `Загрузить файлы на сервер 157.230.11.51? (y/n)`
- Введите **y** и нажмите Enter
- Может попросить пароль от сервера (введите пароль root)
- Начнется загрузка файлов (займет 5-10 минут)

**Пример вывода:**
```
🎵 Загрузка гимнов на сервер

📊 Найдено файлов: 51

Загрузить файлы на сервер 157.230.11.51? (y/n) y
📤 Загружаю файлы...

anthem_at.m4a    100%  450KB   450KB/s   00:01
anthem_us.m4a    100%  520KB   520KB/s   00:01
...
```

### 3.4. Если ошибка подключения

Если видите "Permission denied" или "Connection refused":

1. Проверьте что у вас есть доступ к серверу:
```bash
ssh root@157.230.11.51
```

2. Если не можете подключиться - проверьте пароль или SSH ключи

## 🆘 Если что-то пошло не так

### Проблема: "brew: command not found"

**Решение:** Установите Homebrew:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Проблема: "ffmpeg не найден"

**Решение:** 
```bash
brew install ffmpeg
```

Если brew не работает, попробуйте:
```bash
# macOS через MacPorts
sudo port install ffmpeg

# Или скачайте с https://ffmpeg.org/download.html
```

### Проблема: Скрипт загружает очень долго

**Решение:** Это нормально! Загрузка 51 файла может занять 20-40 минут в зависимости от скорости интернета. Просто подождите.

### Проблема: Некоторые файлы не загрузились

**Решение:** Запустите скрипт еще раз:
```bash
python3 download_real_anthems_complete.py
```

Скрипт пропустит уже загруженные файлы и загрузит только недостающие.

### Проблема: Не могу подключиться к серверу

**Решение:** 
1. Проверьте что сервер доступен:
```bash
ping 157.230.11.51
```

2. Проверьте SSH доступ:
```bash
ssh root@157.230.11.51
```

3. Если не работает - проверьте пароль или обратитесь к администратору сервера

### Проблема: "Permission denied" при загрузке на сервер

**Решение:**
1. Убедитесь что используете правильный пользователь (root)
2. Проверьте что папка `/var/www/flags.worldarena.games/anthems/` существует на сервере
3. Если папки нет - создайте на сервере:
```bash
ssh root@157.230.11.51
mkdir -p /var/www/flags.worldarena.games/anthems
chmod 755 /var/www/flags.worldarena.games/anthems
exit
```
