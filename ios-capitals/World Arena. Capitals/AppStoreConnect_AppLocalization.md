# Локализации приложения для App Store Connect

**Где:** App Store Connect → Ваше приложение → App Information → Добавление локализации (или версия 6.0 → Локализации).

**Ограничения:**  
- **Отображаемое название (Subtitle)** — максимум **35 символов**.  
- **Описание (краткое)** — максимум **55 символов**.  
- **Keywords** — до 100 символов (через запятую, без пробелов после запятой).
