# 🎵 Система гимнов стран - Flags World

## Обзор

Система загрузки и воспроизведения реальных гимнов стран в приложении Flags World. Гимны загружаются из общедоступных источников, конвертируются в оптимальный формат и размещаются на сервере для быстрого доступа.

## 🚀 Быстрый старт

```bash
cd "World Arena. Flags/Scripts/Audio"
./setup_anthems.sh
```

## 🔧 Технические характеристики

### Аудио формат
- **Формат**: M4A (AAC кодек)
- **Битрейт**: 192 kbps
- **Частота**: 44.1 kHz
- **Каналы**: Стерео
- **Длительность**: 1-3 минуты

### Размеры файлов
- **Средний размер**: 2-5 MB
- **Общий объем**: ~100 MB (40 стран)
- **Кэш**: Автоматическое управление

### Источники
- **Wikimedia Commons**: Основной источник
- **Internet Archive**: Альтернативный источник
- **Лицензия**: Общественное достояние

- **Сжатие**: Gzip для аудио файлов

## 🔄 Процесс работы

### 1. Запрос гимна
```swift
AudioManager.shared.playAnthem(for: "ru")
```

### 2. Проверка кэша
- Ищет файл в локальном кэше
- Проверяет целостность файла
- Если найден - воспроизводит

### 3. Загрузка с сервера
- Проверяет доступность сервера
- Загружает файл по HTTPS
- Проверяет размер и формат
- Сохраняет в кэш

### 4. Воспроизведение
- Создает AVAudioPlayer
- Настраивает прогресс-бар
- Запускает воспроизведение

### 5. Fallback
- При ошибках включает симуляцию
- Логирует проблемы
- Показывает пользователю статус

## 🛠️ Разработка

### Добавление новой страны
1. Добавить URL в `anthem_sources` в `download_real_anthems.py`
2. Запустить скрипт загрузки
3. Загрузить на сервер
4. Обновить манифест

### Обновление существующего гимна
1. Заменить файл на сервере
2. Очистить локальный кэш
3. Принудительная перезагрузка
