# 🌎 Flags World Mobile - React Native App

Мобильное приложение для изучения флагов стран мира с викториной и статистикой.

## 🚀 Этап 3: Интеграция с внешними API

### ✅ Реализованные функции:

#### 🌐 REST Countries API интеграция
- Получение данных о странах из https://restcountries.com/v3.1
- Поддержка мультиязычных названий стран
- Автоматическое кэширование данных на 24 часа
- Fallback на локальный кэш при отсутствии сети

#### 📡 Система сетевого мониторинга
- Отслеживание состояния интернет-соединения
- Автоматическое переключение в офлайн режим
- Retry логика с экспоненциальной задержкой
- Синхронизация данных при восстановлении связи

#### 🖼️ Отображение флагов
- Компонент FlagImage с кэшированием
- Fallback на эмодзи при ошибке загрузки
- Индикаторы загрузки
- Оптимизация размеров изображений

#### 💾 Кэширование и офлайн режим
- AsyncStorage для локального хранения
- Кэширование стран по языкам
- Офлайн игры с синхронизацией
- Управление размером кэша

### 🛠️ Технические улучшения:

#### HTTP клиент (Axios)
- Interceptors для автоматического добавления токенов
- Обработка ошибок 401/403
- Retry логика для сетевых ошибок
- Timeout настройки

#### Архитектура сервисов
- `ApiService` - основной API клиент
- `NetworkService` - мониторинг сети
- `useNetworkStatus` - React хук для компонентов
- `NetworkStatusBanner` - UI индикатор

## 📦 Установка и запуск

### Предварительные требования
```bash
# Node.js 16+
node --version

# React Native CLI
npm install -g react-native-cli

# iOS (только для macOS)
cd ios && pod install
```

### Установка зависимостей
```bash
cd mobile
npm install

# Для iOS
cd ios && pod install && cd ..
```

### Запуск приложения
```bash
# Android
npm run android

# iOS
npm run ios

# Metro bundler
npm start
```

## 🔄 API интеграция

### REST Countries API
```typescript
// Получение всех стран
GET https://restcountries.com/v3.1/all?fields=name,cca2,cca3,region,flags

// Поддерживаемые языки
const languages = ['en', 'ru', 'es', 'uk', 'ca', 'zh'];
```

### Backend API
```typescript
// Аутентификация
POST /api/auth/login
POST /api/auth/register

// Игры
POST /api/games/start
POST /api/games/finish

// Статистика
GET /api/statistics
GET /api/statistics/mistakes
```
